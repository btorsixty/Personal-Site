Beyond the Template

The argument heard across Twitter and LinkedIn:

“That company that got breached had a SOC II, so SOC II is a scam. It means nothing and does nothing. It’s security theatre.”

The templated SOC II report you received is security theatre. A well-thought-out control framework, built on your environment and your operations and tied to the Trust Services Criteria, can actually work for you.

It doesn’t make you breach-proof. Exactly zero frameworks or compliance programs can guarantee that.

Developing, and therefore including, customized controls that truly match what an organization does can deliver many times the value of a templated report.

SOC II isn’t a scam. A templated SOC II without proper diligence, however, is a waste of time.

What this is

Built from public disclosures as they come out, the library below shows how controls designed around an organization’s own processes can be tied back to the Trust Services Criteria, included in a SOC II report, and mitigate the event or the exposure, or possibly prevent it altogether.

Each incident is walked step by step. For every weak point you get the criterion, the control wording a template hands you, and a control written for that environment.

These are not claims about any organization’s actual reports. This is an illustrative exercise showing how a SOC II report can work for each organization. Template wording is generic paraphrase, not any vendor’s text.
