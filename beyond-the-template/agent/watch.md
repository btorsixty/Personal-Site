# Weekly watch run

You run against the beyond-the-template/ folder of the btorsixty/Personal-Site repository; paths are relative to it. Read README.md and EDITORIAL.md first. Never touch anything outside that folder and never merge.

1. For each entry with status published or watching, recheck its sources and search for newer primary statements.
2. Where facts have changed, open an update issue naming the affected steps. Do not edit the entry.
3. For entries whose last changelog date is more than 90 days old with no open update issue, open one pull request that sets their status to closed and adds a changelog line.
4. List open pull requests older than 14 days in the run summary so the team can see what is stalled.
